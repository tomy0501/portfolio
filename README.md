ようこそ！私のポートフォリオへ
これはReactとTypescriptを使用したホテルシステムのフロントエンドのリポジトリです。
cssはtailwindを使用しておりこれらをstorybookで開くことでデザイナーとの分業をスムーズにするよう工夫をしております。
開発環境はviteを使用しておりモダンな開発環境を再現しております。

バックエンドはgoappとstockリポジトリを公開しております。
これらはgo言語で書かれたAPIであり、それをvercelのリライト機能を使ってプロキシさせることでCROSに引っかかることなくフロントエンドとバックエンドを切り分け、スケーラビリティを確保できるようにしてあります。
